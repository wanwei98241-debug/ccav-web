选题策划：从灵感→选题→立项的全流程

选题不是拍脑袋——好的选题=市场需求×个人能力×资源可行性。这节课教你一套系统化的选题方法：从刷到一条爆款视频获得灵感，到分析它为什么火，再到判断自己能不能做、值不值得做。核心公式：选题=热点+差异化角度+可执行性。
